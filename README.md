# ShortcutLaunch

Author: Vatsal Gautam

URL: [ShortcutLaunch](https://www.github.com/thundergod60/ShortcutLaunch)

ShortcutLaunch is a powerful and accessible quick-launcher add-on for NVDA. It allows you to launch program, folder, URL or execute any command quickly.

## features:

- Universal launching. Launch files, folders, URLs or shell commands seamlessly.
- Instant searching and filtering through shortcuts you've added.
- A filter box which allows you to filter between folders, programs, or websites (URLs)
- Allows you to set a command to execute in a specific directory, so you won't have to do the repetitive work of CD

## usage:

Press nvda+shift+l to open the ShortcutLaunch dialog.

## keyboard shortcuts:

- NVDA+Shift+L: Opens the ShortcutLaunch dialog.
- Enter: Launch the selected shortcut. Alternatively, pressing alt+l will allow you to perform the same action.
- Alt+D: Deletes the shortcut
- Alt+A: Quickly open add the shortcut window.
- alt+e: Quickly open edit shortcut window.
